# Resume Template

This directory contains a professional resume template in LaTeX format (Jake's Resume style) that showcases the Hospital Management & AI-Featured System project.

## Files

- `resume.tex` - LaTeX source file for the resume

## How to Use

### Option 1: Compile Locally

1. Install LaTeX distribution:
   - **Windows**: Install [MiKTeX](https://miktex.org/download)
   - **macOS**: Install [MacTeX](https://www.tug.org/mactex/)
   - **Linux**: `sudo apt-get install texlive-full` (Ubuntu/Debian)

2. Compile the resume:
   ```bash
   pdflatex resume.tex
   ```

3. The output will be `resume.pdf`

### Option 2: Use Online LaTeX Editor

1. Go to [Overleaf](https://www.overleaf.com)
2. Create a free account
3. Upload `resume.tex`
4. It will automatically compile and show you the PDF

## Customization

Edit `resume.tex` and replace the placeholder information:

- **Line 97-100**: Update your name, phone, email, LinkedIn, and GitHub links
- **Section: Education**: Add your university details, GPA, and coursework
- **Section: Experience**: Add your work experience and internships
- **Section: Projects**: The Hospital Management System is already added - add more projects if needed
- **Section: Technical Skills**: Already populated based on this project - customize as needed
- **Section: Certifications**: Add any relevant certifications

## Template Style

This resume uses Jake's Resume template, which is:
- ATS (Applicant Tracking System) friendly
- Clean and professional formatting
- Easy to customize
- Widely used in tech industry

## Tips

- Keep resume to 1-2 pages
- Use action verbs (Developed, Implemented, Architected, Built, etc.)
- Include quantifiable metrics where possible
- Tailor the resume for each job application
- Proofread carefully before sending
