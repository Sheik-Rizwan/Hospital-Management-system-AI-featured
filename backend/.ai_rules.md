# AI Change Rules (Mandatory)

These rules apply to **all future changes** in this codebase, for **any agent**.

When modifying code:

1. Refactor existing code first before writing new code.
2. Reuse existing functions, variables, and logic whenever possible.
3. Add new code or new functions only if refactoring is not feasible.
4. Do not duplicate logic that already exists in the same file.
5. Preserve existing application behavior.
6. Keep structural changes minimal.
